# latihan_tambahan
Letakkan folder ini di dalam lib/ (lib/latihan_tambahan/).
Butuh package url_launcher (sudah terpasang di toko_tegar). Flutter 3.7+.
Ganti waNomor di util.dart.
Jalankan: ubah lib/main.dart -> runApp(const TokoLatihanApp());
atau: flutter run -t lib/latihan_tambahan/main_tambahan.dart
